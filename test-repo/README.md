# psflow-sample

Тестовый проект для PurpleFlow. Зависимостей нет, тесты — `npm test` (`node --test`, Node ≥ 22.18 запускает `.ts` без сборки).

Пример задачи для критерия приёмки:

> Добавь функцию `slugify(s: string): string` в `src/strings.ts`: переводит строку в kebab-case латиницей (кириллицу транслитерирует), убирает всё кроме букв, цифр и дефисов. Добавь тест.
