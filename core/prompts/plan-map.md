Сопоставь изменённые файлы ветки с пунктами плана, чтобы человек принимал изменения по смыслу, а не по алфавиту.

Пункты плана (`tasks.md`):

{{tasks}}

Изменённые файлы (со счётчиками строк):

{{files}}

Правила:
- Группа — пункт или раздел плана (бери его текст коротко, с номером, например «2. Фоновые локации» или «2.3 Возврат токенов при провале»); выбирай уровень так, чтобы групп было 3–10.
- Каждый файл — ровно в одну группу, самую подходящую. Тесты — в группу того, что они проверяют.
- Файлы, которые не относятся ни к одному пункту, — в группу «Вне плана» (её важно видеть: это возможная лишняя работа).
- Не придумывай файлы, которых нет в списке.

Ответь только JSON: `{ "groups": [{ "title": "…", "files": ["путь", "…"] }] }`
