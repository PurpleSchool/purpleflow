Составь профиль проекта для других агентов, которые будут в нём работать: чтобы им не изучать репозиторий с нуля каждый раз. Только читай, ничего не меняй.

Посмотри: файлы сборки и манифесты, README, структуру каталогов, ключевые модули, конфиги линтеров и тестов, CI, пару типичных файлов кода и тестов.

Напиши Markdown по-русски, только факты из файлов, всего не длиннее 70 строк. Строго эти разделы, каждый — заголовком второго уровня, в таком порядке (раздел без фактов пропусти):

## Стек
языки, фреймворки, ключевые библиотеки и версии

## Структура
главные каталоги и пакеты (монорепо?), где фронтенд, бэкенд, общие модули

## Как устроено
точки входа, слои, где роутинг, где доступ к данным, как ходят в API

## Соглашения
стиль кода, именование, как пишут компоненты, сервисы, обработку ошибок

## Тесты
фреймворк, где лежат, как называют, как запускать

## Запуск
команды разработки, переменные окружения, зависимости (база, очереди)

Внутри разделов — короткие пункты списком, пути и имена в `коде`. Без вступлений и выводов — сразу первый раздел.
